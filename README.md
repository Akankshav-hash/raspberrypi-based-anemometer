# Raspberry Pi Based Anemometer using Python

## Overview

This project implements a **Raspberry Pi-based smart anemometer** for real-time weather monitoring. The system measures wind speed using an IR reflectance sensor and records environmental parameters such as temperature, humidity, and atmospheric pressure using a BME280 sensor. The collected data is processed in Python and stored in CSV format for analysis.

## Features

* Wind speed measurement using IR sensor
* Temperature, humidity, and pressure monitoring
* Real-time data acquisition
* Automatic CSV data logging
* Raspberry Pi based implementation
* Cost-effective and scalable design

## Hardware Used

## How to Run

1. Install Raspberry Pi OS and required Python libraries.
2. Connect the IR sensor and BME280 sensor to the Raspberry Pi.
3. Execute the Python script.
4. View real-time readings and generated CSV logs.
